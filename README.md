# ⚽ Cronómetro Fútbol - Línea de Meta

Sistema de cronometraje automático para fútbol 5 y 7 con detección por cámara.

## 📋 Características

- ✅ Detección automática de cruce de línea de meta
- ✅ Guardado automático en Google Sheets
- ✅ Cálculo de velocidad (km/h y m/s)
- ✅ Gestión de jugadores por categoría
- ✅ Funciona en PC y celular
- ✅ Sin necesidad de instalar nada

## 🚀 Cómo usar

1. Abre `index.html` en tu navegador
2. Selecciona categoría y jugador
3. Configura la distancia de la cancha
4. Pon la cámara de perfil viendo la línea de meta
5. ¡El cronómetro se activa automáticamente!

## 📱 Para usar en celular

Visita: https://tusuario.github.io/cronometro-futbol

## 🔧 Configuración de Google Sheets

1. Crea una hoja en sheets.google.com
2. Ve a Extensiones → Apps Script
3. Pega el código del script
4. Despliega como aplicación web
5. Copia la URL y pégala en `script.js`

## 📊 Datos guardados

- Fecha y hora
- Categoría
- Jugador
- Tiempo
- Velocidad (m/s y km/h)
